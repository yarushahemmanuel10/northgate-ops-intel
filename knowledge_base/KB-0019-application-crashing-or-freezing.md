# Application crashing or freezing

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Symptoms

A business application freezes, closes unexpectedly or shows an error when it opens or when the user saves a file.

## Steps

1. Note the exact error message and what the user was doing when it happened.
2. Ask whether other users of the same application see the same problem. If several do, the problem is likely with the application itself or its server, not the user's computer.
3. Restart the computer and try again. Many freezes clear after a restart.
4. Check for updates to the application and install them. Vendors often fix crashes in updates.
5. Repair the application from Apps and Features if the option exists.
6. Clear the application's local cache or temporary files if the vendor's guidance says it is safe to do so.
7. If the crash only happens with one file, try opening a copy of the file. The file may be damaged; restore an earlier version from version history or backup if needed.

## When several users are affected

Raise the priority if the application is critical to the business and several users cannot work. Contact the application vendor's support with the error details; the customer's documentation lists the vendor support route.
