# Restoring deleted files

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when a user has deleted a file or folder by mistake, or needs an earlier version of a file.

## Check the quickest options first

1. **Recycle bin.** Ask the user to check the recycle bin on their computer and in the online file library. Many deletions can be undone there in seconds.
2. **Version history.** For documents stored in the cloud file library, open version history and restore the earlier version the user needs.

## Restoring from backup

If neither option works, restore from backup:

1. Confirm exactly what is needed: the file or folder name, where it was, and roughly when it was last correct.
2. Nightly backups are kept for 30 days. If the user needs a file from longer ago than that, explain that it cannot be recovered from backup.
3. Restore the file or folder from the most recent backup taken before the deletion or damage.
4. Restore to the original location unless the user asks otherwise. If restoring would overwrite newer work, restore to a separate folder and let the user compare.
5. Ask the user to open the restored file and confirm it is the right version.

## Prevention

Remind the user to keep work on the shared drive or cloud library, not only on their desktop, so it is included in backups.
