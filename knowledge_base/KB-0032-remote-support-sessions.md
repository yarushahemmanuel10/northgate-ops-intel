# Remote support sessions

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## What a remote support session is

Many problems can be fixed without a visit. With the user's permission, an agent connects to their computer over the internet, sees their screen and, if the user agrees, takes control of the mouse and keyboard.

## Starting a session

1. The agent asks the user to open the remote support tool from the start menu or the system tray.
2. The tool shows a session code. The user reads the code to the agent.
3. The tool asks the user to allow the connection. Nothing happens until the user agrees.
4. The agent can see the screen. The user can watch everything the agent does and can end the session at any time.

## Good practice for agents

- Always ask before taking control, and say what you are about to do.
- Ask the user to close any windows showing personal or confidential information before you connect.
- Never ask the user to tell you their password. If a password must be typed, let the user type it.
- End the session when the work is done, and confirm the tool has disconnected.

## Problems suited to remote sessions

Remote sessions work well for application crashes, failing updates, adding printers and Outlook problems. They are not suitable when the computer will not start, when the network connection itself is the problem, or when hardware needs to be replaced.

## If the tool will not connect

Check the computer has an internet connection. Some guest or hotel networks block remote support tools; ask the user to try another network.
