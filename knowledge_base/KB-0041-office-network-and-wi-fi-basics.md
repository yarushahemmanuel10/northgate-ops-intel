# Office network and Wi-Fi basics

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## How the office network fits together

Each office has a managed router that connects to the internet, a wired network for desks and printers, and wireless access points for laptops and phones. Many sites also have a backup mobile connection that takes over automatically if the main line fails. Northgate monitors the router and access points remotely.

## Wi-Fi networks

Most offices have two wireless networks:

- the **staff network**, for work devices, which can reach printers and the shared drive
- the **guest network**, for visitors and personal phones, which can reach the internet only

Connect work devices to the staff network. Devices on the guest network cannot print or open the shared drive.

## If the whole office loses internet

Phone the service desk straight away: this is a P1 or P2 and must be reported by phone, not email. Please do not switch the router off and on; our engineers need its logs to find the fault, and restarting it can interrupt the switch to the backup connection.

## If Wi-Fi is slow in one area

Report which rooms are affected and when. Slow Wi-Fi in one area usually points to a failed access point or a coverage gap after a layout change, both of which we can fix.

## If one device cannot connect

Forget the network on the device and join it again. If that does not work, restart the device and contact the service desk.
