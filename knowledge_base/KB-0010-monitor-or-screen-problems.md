# Monitor or screen problems

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Symptoms

A second monitor is not detected, the screen flickers or shows lines, or the display is blank while the computer is clearly running.

## Second monitor not detected

1. Check the cable at both ends and confirm the monitor is switched on and set to the right input.
2. If the monitor connects through a docking station, unplug the dock's power for a moment and reconnect it.
3. Open the display settings and use the option to detect displays.
4. Try a different cable. Display cables fail more often than monitors do.
5. Update the graphics driver from the device manager or the manufacturer's update tool.

## Flickering, lines or discolouration

1. Move the monitor to a different computer, or connect a different monitor to this computer, to find out which part is at fault.
2. If the fault follows the monitor, the monitor is failing. Swap it for a spare and log a warranty claim if it is still covered.
3. If the fault follows the computer, update the graphics driver. If that does not help, book an engineer.

## Built-in laptop screen

If a laptop's own screen is cracked, blank or flickering but an external monitor works, the screen needs repair. Lend the user a spare laptop if one is available and arrange the repair.
