# Setting up new equipment

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when new equipment has been delivered and needs setting up for a user: a laptop, a desktop, a docking station or monitors.

## New laptop or desktop

1. Check the delivery against the order and note the serial number on the ticket.
2. Enrol the device in device management so it receives the customer's security settings and standard apps.
3. Sign in as the user, or with the user present, and check that email, the shared drive and any line-of-business apps open correctly.
4. If the device replaces an old one, copy any files the user kept locally. Encourage the user to keep files on the shared drive in future.
5. Wipe and re-enrol the old device, or prepare it for disposal, as the customer prefers.

## Docking station and monitors

Most setups can be done remotely with the user plugging in the equipment. Where the customer has asked for a visit, an engineer attends, connects the dock and monitors, arranges the displays and tests with the user.

## Before closing

- Confirm the user can sign in and print.
- Confirm multi-factor authentication works on the new device.
- Record the asset on the customer's equipment list.
