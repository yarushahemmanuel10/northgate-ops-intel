# Saving files so they are backed up

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Where to save your work

Save work to the **shared drive** or the **cloud file library**, not only to your desktop or documents folder. Files in these places are backed up every night and can be restored if something goes wrong.

Files saved only on your laptop are lost if the laptop fails, is stolen, or has to be wiped.

## How backups protect you

- Nightly backups are kept for 30 days. A file deleted or damaged within that period can usually be restored.
- Cloud files also keep a version history, so you can often get back yesterday's version yourself.
- Deleted files go to the recycle bin first. Check there before contacting the service desk.

## If you delete something by mistake

1. Check the recycle bin.
2. For cloud files, check version history.
3. If neither works, contact the service desk through the portal with the file name, where it was, and when it was last correct.

## What backups do not cover

- Files saved only on your laptop's desktop.
- Files on USB sticks or personal cloud accounts.
- Anything deleted more than 30 days ago.
