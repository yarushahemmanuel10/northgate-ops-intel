# Resetting a password or unlocking an account

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when a user is locked out after too many failed sign-in attempts or has forgotten their password.

## Verify who you are speaking to

Never reset a password for someone you cannot verify. Check the caller against the customer's list of authorised contacts, or call them back on the number held for them. If the request arrives by email, reply asking the user to phone the service desk. Record how you verified the user on the ticket.

## Unlocking an account

1. Find the user in the admin centre and check whether the account is locked or disabled.
2. If it is locked because of failed attempts, unlock it.
3. Ask the user whether they made the failed attempts. If they did not, treat it as a possible compromised account and follow that article instead.

## Resetting a password

1. Reset the password in the admin centre and choose the option that makes the user set a new password at their next sign-in.
2. Give the temporary password to the user by phone, never by email.
3. Remind the user of the password standard: at least 12 characters, and multi-factor authentication stays on.
4. Ask the user to sign in while you are still on the phone so you can confirm it worked.

## Self-service reset

Where the customer has self-service password reset enabled, enrol the user if they are not already enrolled, and show them how to use it next time. This saves them waiting for the service desk and reduces calls.

## Devices that keep locking the account

If the account locks again soon after you unlock it, an old password is probably saved somewhere, often on a phone mail app or a second computer. Ask the user to update the password on every device that uses their account.
