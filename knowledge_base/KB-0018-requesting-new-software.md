# Requesting new software

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when a user asks for software to be installed on their computer.

## Approval

Software requests must be approved by the user's manager, because they may involve licence costs and security risk. Ask the manager to confirm on the ticket. Software that the customer has already approved for everyone, such as the standard office apps, does not need approval.

## Steps

1. Check whether the software is in the customer's software portal. If it is, the user can install it themselves from the portal, and you can show them how.
2. If the software needs a licence, check whether the customer has a spare licence. If not, ask the manager whether to buy one and raise the purchase separately.
3. Install the software remotely through device management where possible, rather than installing it by hand.
4. Ask the user to open the software and confirm it works before closing the ticket.

## Software we will not install

Do not install software from unofficial download sites, cracked software, or tools that would let the user bypass security settings. Explain why to the user and suggest an approved alternative if there is one.
