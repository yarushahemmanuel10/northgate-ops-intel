# Printer showing offline

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Purpose

Use this guide when users report that a printer is offline or that nothing comes out when they print.

## One user or everybody?

Start by finding out who is affected. If nobody can print, look at the printer and the network. If only one person is affected, look at that person's computer.

## Nobody can print

Check the printer's screen for errors such as jammed paper or an open tray. Print a configuration page and note the printer's network address. Compare it with the address the computers or print server use. After a power cut or a router change, printers sometimes come back with a different address. If that has happened, reserve the address on the router or server so it stays fixed, and correct the printer port.

## Jobs not printing

Open the print queue, cancel anything stuck, restart the print spooler service, and print a test page.

## Still failing

Turn the printer off and back on and try again. If the printer reports a hardware fault, book a visit or contact the customer's printer maintenance supplier if they have one.
