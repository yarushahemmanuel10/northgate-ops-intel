# Laptop or PC will not start

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Symptoms

The computer does not power on at all, or it powers on but stops on a black screen or the manufacturer's logo.

## No power at all

1. Check that the power adapter is plugged in at the wall and into the laptop, and that the wall socket works with another device.
2. Look for a charging light on the laptop or adapter. No light usually means the adapter has failed.
3. Try a known working adapter of the same type. Field engineers carry spares, and most customer sites have one in stock.
4. Hold the power button down until any lights go off, release it, then press it once to start.
5. For desktops, check the power cable at the back and the switch on the power supply.

If a replacement adapter brings the laptop back, the original adapter has failed. Replace it and close the ticket.

## Stuck on a black screen or the logo

1. Disconnect docking stations, external drives and USB devices, then restart. A faulty accessory can stop the computer starting.
2. If the computer has just installed updates, let it sit for a while before deciding it is stuck. Interrupting an update can make things worse.
3. If it still does not start, use the recovery options to run startup repair.
4. If startup repair fails, arrange for an engineer to collect or visit the device.

## Protect the user's work

Ask whether the user saves their files to the shared drive or cloud storage. If they keep important files only on the laptop, tell the engineer before any repair that might wipe it.

## Priority

A single laptop that will not start is a P3, raised to P2 if the user has no other device and cannot work, for example a lone finance user on payroll day.
