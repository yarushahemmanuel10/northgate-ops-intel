# Reporting a suspicious or phishing email

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## What users should do

When a user receives an email that looks suspicious, such as an unexpected invoice, a request to confirm a password, or a message that creates urgency, they should:

1. **Not** click links, open attachments or reply.
2. Use the **report button** in their email client to report the message as phishing.
3. **Not** forward the email to the service desk or colleagues. Forwarding spreads the message and can make links clickable again on other devices.
4. Phone the service desk if they have already clicked a link or entered their password.

## What the service desk does

1. Find the reported message in the security portal.
2. Check whether the same message reached other mailboxes in the business, and remove it from all of them.
3. Block the sender or sending domain if the message is clearly malicious.
4. Ask the user whether they clicked anything or entered any details.
5. If the user entered their password, follow the compromised account article straight away.
6. If nobody interacted with the message, close the ticket and thank the user for reporting it.

## Priority

A single reported phishing email with no interaction is a P3. Raise it to P2 if several staff received it and someone clicked a link, or if a finance user received a payment request.
