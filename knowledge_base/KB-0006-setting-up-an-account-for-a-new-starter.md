# Setting up an account for a new starter

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when a customer asks for a new member of staff to be given an account, email address and access to shared files.

## What the request must include

Ask the manager to provide the following on the ticket before you start:

- the new starter's full name and job title
- their start date
- which team they are joining, so you can copy that team's access
- any specific systems, shared mailboxes or shared drives they need
- whether they need a laptop or other equipment ordered

If equipment is needed, raise a separate request through the shop so it arrives in time.

## Creating the account

1. Create the user from the customer's starter template where one exists. The template sets the standard groups, licence and mailbox settings for that customer.
2. Assign the licence agreed for the role.
3. Add the user to the security groups for their team's shared drive and shared mailboxes.
4. Set a temporary password that the user must change at first sign-in.
5. Make sure multi-factor authentication registration is required at first sign-in.

## Handing over

Send the sign-in details to the line manager, not to the new starter's personal email address. The manager passes them on on the first day. Tell the manager the new starter will be asked to set a password of at least 12 characters and to register an authenticator app.

## First day

If the new starter has trouble signing in on their first day, help them register multi-factor authentication over the phone. Check that their shared drive and shared mailboxes appear before closing the ticket.
