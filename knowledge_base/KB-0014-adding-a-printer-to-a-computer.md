# Adding a printer to a computer

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when a user cannot see a printer in their list of printers, or needs a printer added after moving desks or getting a new computer.

## Preferred method: deploy by policy

Where the customer's printers are deployed through device management or group policy, add the user or the computer to the right group and ask the user to restart. The printer appears automatically with the correct driver. This is the preferred method because the printer comes back on its own if the computer is replaced.

## Manual method

1. Find the printer's name or network address on the customer's documentation, or on a configuration page printed from the printer.
2. On the user's computer, open printer settings and add the printer by name or address.
3. Install the driver if prompted. Use the driver from the manufacturer's website, not an old copy from a file share.
4. Print a test page and ask the user to confirm it came out.

## If the printer still does not appear

Check that the computer is on the same network as the printer. Guest Wi-Fi networks usually cannot reach office printers. If the user is working from home, explain that office printers are not available from home.
