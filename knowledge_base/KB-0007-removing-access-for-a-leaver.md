# Removing access for a leaver

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## When to use this article

Use it when a customer tells us a member of staff is leaving and their access must be removed.

## Timing

Accounts are disabled on the leaving date. If the manager asks for access to end immediately, for example after a dismissal, disable the account straight away and record who asked and when.

## Steps on the leaving date

1. Block sign-in for the account and sign the user out of all active sessions.
2. Reset the password so any saved passwords stop working.
3. Remove the user from security groups, shared mailboxes and distribution lists.
4. Convert the mailbox to a shared mailbox and give the line manager access, so customer emails are not lost. The manager keeps access for 30 days, after which the mailbox is reviewed with the customer.
5. Set up an automatic reply or email forwarding if the manager asks for one.
6. Remove licences that are no longer needed and record the change on the ticket so the customer's billing can be updated.

## Devices

Ask the manager to return the leaver's laptop and phone. When they arrive, wipe and re-enrol them before they are given to someone else. Remove the old device from the device management console.

## Files

Files the leaver kept in personal cloud storage should be moved to a shared location the manager can reach before the account is removed completely. Ask the manager where they want the files to go.
