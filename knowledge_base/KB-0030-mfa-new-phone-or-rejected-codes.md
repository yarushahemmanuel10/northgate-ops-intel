# MFA: new phone or rejected codes

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Purpose

Use this guide when a user cannot get past the multi-factor authentication step at sign-in.

## Verify first

Treat any change to a user's sign-in methods like a password reset: confirm the caller is the account holder before doing anything.

## New phone or app removed

Remove the user's old authenticator registration in the admin centre. Then **arrange a short call or visit and register the new phone together with the user**: the engineer or agent completes the registration steps on the user's phone while the user watches, so that the registration is done correctly first time. Do not leave the user to re-register on their own.

## Codes not accepted

Authenticator codes rely on the phone's clock being correct. Ask the user to switch on automatic date and time on the phone; codes will then work.

## Prompts the user did not trigger

Tell the user to deny the prompt. Reset their password and work through the compromised account guide, because someone else may know the password.
