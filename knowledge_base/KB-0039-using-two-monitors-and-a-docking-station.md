# Using two monitors and a docking station

> Synthetic document. Northgate IT Services Ltd is a fictional company; this text was written for a portfolio prototype.

## Setting up

1. Connect the docking station to power, then connect it to the laptop with its cable.
2. Connect each monitor to the docking station and switch the monitors on.
3. Open the display settings on the laptop. The monitors appear as numbered boxes. Drag them so their layout matches the desk, which makes the mouse move naturally from one screen to the next.
4. Choose which screen is the main display. The taskbar and new windows appear there.

## Common problems

**A monitor stays blank.** Check the monitor is on and set to the right input. Unplug the dock's power for a moment and reconnect it. Try a different cable.

**The layout resets every morning.** This usually happens when the laptop connects to the dock in a different order. Update the dock's firmware and the laptop's graphics driver.

**Screens flicker or show lines.** Swap the monitor with a working one to see whether the fault is in the monitor or the computer, then follow the monitor problems article.

**Laptop not charging on the dock.** Check the dock's power adapter is connected and that it is the adapter supplied with the dock. Some docks cannot charge larger laptops.

## Getting new equipment set up

New docks and monitors can be ordered through the shop. Most users can set them up with phone guidance; an engineer visit can be booked if needed.
